# Bài tập C++: Tính tổng hai số

## 1. Mô tả bài toán
Viết chương trình C++ cho phép người dùng nhập vào hai số. Chương trình tính tổng và hiển thị kết quả ra màn hình.

## 2. Kiến thức sử dụng
- Khai báo biến kiểu `double`.
- Nhập dữ liệu bằng `cin`.
- Xuất dữ liệu bằng `cout`.
- Sử dụng phép toán cộng (`+`).

## 3. Tệp trong repository
- `main.cpp`: Mã nguồn của chương trình.
- `README.md`: Tài liệu mô tả bài toán và hướng dẫn chạy.

## 4. Cách biên dịch và chạy

### Cách 1: Sử dụng trình biên dịch g++ (Windows, macOS hoặc Linux)
Mở Terminal tại thư mục chứa file `main.cpp`, sau đó chạy:

```bash
g++ main.cpp -o main
```

Chạy chương trình:

- Windows:
```bash
main.exe
```

- macOS / Linux:
```bash
./main
```

### Cách 2: Sử dụng Visual Studio Code
1. Mở thư mục chứa `main.cpp` bằng Visual Studio Code.
2. Đảm bảo máy tính đã cài trình biên dịch C++ (ví dụ: g++).
3. Mở Terminal trong Visual Studio Code.
4. Thực hiện lệnh biên dịch và chạy như hướng dẫn ở Cách 1.

## 5. Ví dụ minh họa

**Dữ liệu nhập:**
```text
Nhap so thu nhat: 5
Nhap so thu hai: 7
```

**Kết quả:**
```text
Tong cua hai so la: 12
```
